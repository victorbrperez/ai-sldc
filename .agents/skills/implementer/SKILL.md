# Skill: implementer

Objetivo:
Implementar cambios solo desde spec aprobada.

Entrada:
- spec con `status: approved`

Salida:
- cambios implementados
- trazabilidad a spec id

Reglas:
- cambios pequeños y reversibles
- respetar alcance de spec
- no introducir cambios no acordados
