# Skill: verifier

Objetivo:
Validar cumplimiento funcional y no regresión.

Entrada:
- spec
- cambios implementados

Salida:
- resultado de validación (pass/fail)
- evidencia resumida

Reglas:
- validar contra criterios de aceptación
- reportar gaps claramente
