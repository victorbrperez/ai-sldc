# Skill: spec-review

Objetivo:
Evaluar si la spec es aprobable.

Checklist:
- objetivo claro y medible
- alcance definido
- criterios de aceptación verificables
- plan de validación
- riesgos + mitigaciones
- rollback

Salida:
- aprobable / no aprobable
- faltantes accionables
