# Skill: spec-writer

Objetivo:
Convertir la información de intake en una spec clara y completa.

Entrada:
- datos de intake
- template oficial

Salida:
- spec en `specs/active/`
- estado sugerido

Reglas:
- 1 solicitud = 1 spec.
- Criterios de aceptación testeables.
- Redacción concreta, sin ambigüedad.
