# Skill: intake

Objetivo:
Obtener datos críticos mínimos con preguntas cortas y precisas.

Entrada:
- type: feature | change | bugfix
- contexto inicial

Salida:
- respuestas estructuradas
- vacíos de información
- recomendación de estado: draft o ready_for_review

Reglas:
- Priorizar preguntas que desbloquean decisiones.
- Evitar preguntas redundantes.
- No implementar.
